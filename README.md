# Desk Cat – aktualizácie

Tento repozitár slúži len na zverejňovanie aktualizácií appky Desk Cat (mačka na ploche).
Každé vydanie (Releases) má tag `vX.Y.Z` a priložený súbor `desk-cat-update-X.Y.Z.zip`.
Appka ho sama nájde cez **Nastavenia → Všeobecné → Vyhľadať aktualizácie** (alebo raz za deň automaticky),
stiahne, nainštaluje a reštartuje sa.

## Ako to funguje
- `latest.json` – číslo najnovšej verzie a cesta k balíku.
- `releases/desk-cat-update-X.Y.Z.zip` – balíky aktualizácií.
